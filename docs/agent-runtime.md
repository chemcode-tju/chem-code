# 在研究对话里搜索和操作远程服务器

对不确定的公开问题，Agent 可以调用 `web_search`，再用结果中的来源链接回答。每次只向搜索服务发送查询词。默认使用 [Mwmbl 搜索 API](https://developer.mwmbl.org/)，无需模型供应商的搜索权限；索引对某些中文或小众问题覆盖有限。可以设置 `CHEMISTRY_SEARXNG_URL` 改用启用 JSON 格式的 [SearXNG](https://docs.searxng.org/dev/search_api.html)，或设 `CHEMISTRY_WEB_SEARCH_ENABLED=false` 关闭。无结果、超时和被限流都不能当作已核实的事实。

本地运行服务时，在其 .env 中设置 `CHEMISTRY_SSH_HOSTS=cluster-b`（多个别名用逗号隔开），并事先确保运行服务的系统用户可用 OpenSSH 非交互登录该别名、已信任主机密钥。重启服务。在对话中发送：

```text
/shell cluster-b
请查看我当前排队的作业，列出作业号、分区和状态。
```

首行只授权这一轮使用这个别名。命令以远端账号的实际权限运行，可读写文件；工具记录保留命令、退出码和有长度上限的 stdout/stderr。每次命令由独立的远端 `sh` 执行，不保留上一次的工作目录，单次连接最多 30 秒。交互密码、任意主机和共享账号部署都不支持。本工具用于终端操作；VASP 方案仍通过 AiiDA 跟踪、确认、提交。命令超时或连接中断不证明远端已撤销操作。

## 从消息到结果

1. 浏览器为一条消息生成固定请求号。服务端写入 SQLite 后才返回收据；重复发送同一编号不会重复建任务。
2. `chat_queue` 按会话顺序执行，ChatGPT 请求另外按账户排队。离开页面不会取消推理。
3. `agent` 选择已注册的工具，`context` 按模型窗口预留输出，压缩已结束的对话和过长的工具结果。特别长的单轮任务按已完成的工具组折叠，保留用户原话和最近一组调用及其结果。原始记录与给模型的摘录分开。
4. `runtime/live.py` 给页面发送 SSE 草稿。重新连接先收到当前正文，再接增量；工具参数、内部推理和压缩摘要不会作为回答流出。只有模型完成并且数据库事务成功，才算已保存的正式回答。
5. `runtime/checkpoint.py` 在运行工具前记录执行边界，工具完成后保存全部已知结果。服务重启自动接回排队和安全的模型阶段。如果执行途中中断、无法判断外部操作是否完成，会显示“结果未知”，请核查对应的作业或文件。重启前老版本留下的执行中记录无法推断为可安全重放。
