# Chem Code 界面设计规范

本规范适用于聊天、研究方案、步骤与结果、结构与轨迹、设置和科研记忆。新增功能和修改现有界面都必须沿用本规范，避免再创建一套独立视觉样式。

2026-11-17 修订：按用户最新指定的 **[Solid Glass](https://github.com/deeplethe/solid-glass)** 统一视觉材质，取代此前的 DeepSeek Harness 外观。沿用原有信息层级与交互约定：清晰、安静、可长期阅读的科研工作台，视觉主角是研究内容、结构和数据。可交互标题、展开内容和同级模块必须一眼可分。

## 1. 内容与层级

- 保留 Chem Code 猫标志和 Montserrat 品牌字；正文使用系统字体，代码、技术 ID 和科学数值可用等宽字体。
- 一屏先回答一个主要问题。聊天以答复为主；方案以研究步骤和依赖为主；详情先呈现结果与异常；查看器以结构为主。
- 默认只显示对象名称、关键状态和当前操作。参数、内部 ID、原始输出、解释性细节放入有明确名称的展开项。
- 不通过缩小字号塞入更多内容。重复细节删除或归入详情，不能把错误、权限状态、科学单位或数据来源藏到无法发现的位置。
- 一项数据由一个来源计算。方案完成、调度完成、电子/离子收敛、科学结论分别表达，不互相代替。缺失数据不显示成零。
- 图表使用真实采样点、单位与坐标范围，不加视觉平滑伪造趋势。状态同时用文字/形状表达，不只依赖颜色。

## 2. 唯一视觉基础

实现入口是 `src/chemistry_agent/web/theme.css`；Solid Glass 原始明暗配色与材质变量位于 `vendor/solid-glass/tokens.css`，固定上游版本与 MIT 许可见该目录的 `ORIGIN.md` 和 `LICENSE`。`solid-glass.css` 将原始材质适配到现有原生组件，放在各页面组件样式之后加载。旧 Harness token 仅作兼容映射，新增组件使用公共语义 token，不另建浅色/深色常量，也不为换肤迁移框架。

| 用途 | Token / 数值 |
| --- | --- |
| 主阅读区域 | `--surface` |
| 侧栏、画布背景 | `--sidebar-fill` |
| 内嵌面板 | `--panel` |
| 内容卡片 | `--card` |
| 菜单、弹出卡、对话框（最厚） | `--raised` |
| 正文 / 次级文本 | `--text` / `--muted` |
| 边界 / 控件边界 | `--border` / `--strong-border` |
| 悬停 / 选中背景 | `--hover` / `--selected`，保持中性 |
| 数据、选中节点、焦点 | `--accent`，不大面积染色 |
| 主要操作 | `--primary` / `--on-primary`，近黑与反白 |
| 聊天阅读 | `--reading-size: 16px`，行高 1.75；尊重用户已保存字号 |
| 主标题 / 分节标题 | 20px / 16px，字重 600 |
| 普通界面 / 次级信息 | `--font-size-ui: 14px` / `--font-size-secondary: 13px` |
| 控件 / 面板 / 大容器圆角 | `--radius-control` / `--radius-panel` / `--radius-dialog`；对应上游约 11 / 14 / 20px |
| 普通控件与菜单行高 | `--control-height: 34px`；紧凑图标 30–34px |
| 菜单内边距 | `--menu-padding: 4px`；表单弹出卡 12px |
| 交互时长 | `--motion-fast: 120ms` / `--motion-expand: 180ms` |

间距使用 4px 基数；常见行内间距 8px、面板内距 16–24px。不要给同级模块逐个选择不同圆角。

正常可读文字对比度至少 4.5:1。`--faint` 仅用于占位与非关键信息，不能用它承载正文。12px 仅用于图轴、紧凑状态/分支计数、键盘提示和轨迹刻度；不增加小于 12px 的可读文字。图标自身的几何尺寸不属于文字字号。

材质层级为薄面板 → 卡片 → 近乎不透明的弹出层。表面保持中性、平整，以顶部细高光、内缘与底部柔影体现厚度；使用 `--glass-shadow`、`--control-shadow`、`--floating-shadow`，不要再叠加双重边框。悬停、选中和菜单展开统一使用 `--selected` 与 `--state-shadow`；选中勾选、状态文字和键盘焦点仍独立保留。

仅小型弹出层使用上游 blur；大型侧栏、密集看板/画布卡片和 3D 查看区不添加逐层背景模糊，避免固定控件定位变化与持续重绘开销。长篇答复不套玻璃卡片；科学图表和原子配色不随材质改变。保持均匀页面底色，不增加环境光团、装饰渐变或图标色块。支持减少透明度、减少动态效果与强制颜色模式。

## 3. 菜单、展开项与表单

- 一级、二级、三级菜单统一 `--raised` 表面、材质细边、`--radius-panel` 圆角和同一浮层阴影。菜单项使用 `--radius-control` 圆角、34px 最低高度、6px 10px 内距、14px 字号。
- 宽屏级联菜单相邻展开，以细线分列；可用宽度不足时仅显示当前一级，提供“返回”。不可把三列挤出视口或缩小文字。
- 悬停是中性背景；选中有勾选或 `aria-checked`；子菜单有方向提示和 `aria-expanded`。焦点环不能去掉。
- 上下键移动，左右键进入/返回，Escape 关闭并返回触发器，Tab 可离开。返回上一级时恢复原分支焦点。
- 同一页面只打开一组选择菜单。`chem:menu-open` 负责协调模型、权限、普通下拉框和附件入口。选择值只由原表单或业务状态保存。
- 弹出层需根据上下空间定位，内容长时在层内滚动；窗口变化不丢失焦点或把菜单留在屏幕之外。
- 一级展开条使用中性 `--panel` 底色、1px 边框、8px 圆角、至少40px高度，同级之间间隔8px。左侧标题/图标，右侧常驻展开箭头。摘要写内容名称，不重复“点击查看”等说明。
- 展开内容以缩进、左侧细导轨和内距与标题区区分。少量互斥的二级内容（如 INCAR/KPOINTS）用分段标签切换同一内容区域，禁止再套一层上下展开。保留键盘切换、选中与焦点状态。
- 表单标签常驻且易读，错误紧邻字段；只读与可编辑状态清楚区分。

## 4. 各工作区约定

### 聊天与主布局

左侧导航和顶部工具栏构成同一中性外壳，不以贯穿整页的竖线切成三个盒子。浅色模式使用灰色外壳、白色对话与研究内容区；研究标签栏采用灰色，下面的方案工具栏与内容区采用白色（深色模式用对应内容表面），切换空态或真实方案时保持相同分层。下方对话与研究面板共享一个内嵌内容区，只有整体外沿使用 `--radius-panel` 圆角，内部保留一条轻边界。研究顶栏固定44px、始终单行。所有工作区共用相同的侧栏宽度与响应式规则，切换方案、结构、进度或工具不能改变顶栏位置；窄栏标签保留相同关闭按钮占位，选中态不能改变标签宽度。手机与最大化模式保留独立内容区圆角。

侧栏拖动保持内容透明度；鼠标悬停或拖动时沿现有整条分隔线做中性高亮，不在旁边另画短柄，不使用蓝色。鼠标命中范围不随细线缩小，键盘焦点仍可见。收起与恢复不播放列宽过渡。左右侧栏开关保留32px命中尺寸及18px图标，默认无外框、无底色，水平对齐。

正文和输入区共享阅读宽度。输入区 16px 圆角，工具条优先保持一行；模型名可省略显示但保留完整标题，权限与发送始终可用。极窄区域采用明确换行布局，不逐个控件随机换行。

输入框上方使用内收的中性设置条，依次为服务器、可选文件夹、作业监控；下方左侧为附件与权限，右侧为上下文、Agent/模型/推理强度与发送。上方三个选择不再混入模型菜单。工作目录与监控按对话保存，不设置独立的研究空间管理页；文件夹可留空自动创建。

右侧面板使用纯图标入口，保留辅助名称和提示。添加标签页只显示右侧加号，与最大化按钮有竖向分隔；面板标签可以关闭和重新打开，折叠面板不等于关闭其标签。顶部标签始终单行，窄宽度、多标签时收为图标并保留完整辅助名称和悬停提示，仅当前标签显示关闭按钮；所有标签仍可见。侧栏拖动先停在300px最小宽度，再继续向外拖动60px才收起；展开恢复已有标签。四个工作区启动入口以同样的中性描边行区分。聊天历史不显示气泡图标；折叠侧栏不再显示额外文件夹入口。新对话图标在侧栏折叠/展开时位置和尺寸一致，展开仅增加文字。科研记忆使用brain图标，与项目文件夹区分。

项目行以关闭/打开文件夹图标表达折叠状态，右侧依次为项目设置（竖向省略号）和新对话加号，折叠时仍可操作；不显示数量、额外箭头、左侧竖线或底部操作文字。项目名称与下方聊天文字对齐，当前聊天使用中性浅底色。操作按钮与折叠控件分离，点击设置或加号不能同时切换折叠状态。

已结束且没有工具或过程内容时，只显示用时，不生成空折叠。系统生成的修订指令不回显为用户引用，但真实外部引用保留。

过程摘要直接显示用时和展开箭头；“处理过程”仅保留为辅助名称。后台计算更新按普通助手消息显示，不添加“计算更新”标题或特殊左边线，保留正文、结果与过程记录。

“查看方案”使用与生成文件区域等宽的整行入口。答复复制按钮放在整条助手消息末尾，即正文、方案入口和生成文件之后，使用12px图标，按钮外框同步收紧为20px、内边距4px；流式复制在过程折叠外，代码块复制保持在代码块内。新对话使用方框编辑笔图标；引用回归双引号图标，显示为14px，保留足够按钮命中范围。

生成文件采用一份列表，默认显示3项，只提供一个“展开全部 N 个文件 / 收起”操作。所有文件类型遵循同一规则；不可再套“其他文件”折叠。查看、下载、引用使用眼睛、下载托盘、引用图标，按钮有完整辅助名称和悬停提示。刷新保留展开选择与滚动位置。

进度页以当前方案 runtime 中的研究步骤为准，分为“需处理”“进行与等待”“已结束”；历史事件另行折叠。失败重试后的旧失败及已完成研究步骤下的旧失败作业只在历史中保留，不能重复计为当前异常；修复后重新等待、下游解除阻塞立即按 runtime 更新。缺少方案状态时才回退到最新事件，并识别修复待执行事件。颜色、文字、分组与数量共同表达状态；未知状态保持中性，不臆断为成功。结束不代表科学收敛。

### 方案画布

- 方案提供“看板 / 画布”切换，首次进入默认看板；按方案保存本次浏览的视图选择、画布位置与看板滚动位置。看板用于定位当前步骤，画布用于查看依赖。
- 看板按研究步骤的 runtime 分为“待执行、进行中、需处理、已完成”；停止/取消单独归入“已停止”，未知状态归入“其他状态”，后两列无内容时隐藏。等待依赖属待执行，排队/准备属进行中，失败/阻塞/暂停属需处理；卡片保留具体状态文字。历史子作业失败不覆盖研究步骤当前状态，已完成不等同科学收敛。
- 看板默认上下两行组织状态区（四种状态为2×2，五/六种状态为3×2），各区列表独立滚动；选项菜单可切回单行，按方案记住选择。看板使用中性列背景、紧凑卡片、状态标记与列计数；点击卡片复用步骤详情，不增加第二个计算入口。窄面板在看板内部横向滚动，保持列和字号可读。不提供“全部分支”筛选器，也不恢复旧的分支筛选状态；画布节点的依赖折叠保留。不提供拖动修改真实执行状态的操作。

- 全部真实依赖线保留。默认细中性线；悬停、键盘聚焦或选中步骤时才强调相关边及方向。提供“全部方向”选项，用户需要时可恢复全图箭头。
- 只有当前步骤采用强调边框，邻居保持中性；保留 24px 点阵作为平移/缩放参照。
- 方案侧栏本身就是看板/画布工作区，铺满可用区域，不再显示外层标题、目标、版本和进度摘要，也不再套卡片框。确认执行、暂停推进和恢复操作融合进视图工具栏；多方案通过紧凑选择器切换。移除展示不删除原始方案数据。
- 卡片主要显示两行标题和一个状态；10px 12px 内距，状态距标题6px。完整标题通过悬停及步骤详情可读，不用大面积空白撑高卡片。
- 新建步骤标题通常控制在15–22个中文字符或等量文字，表达“研究对象 + 动作 + 关键区分”；方法、长条件及理由写入 `purpose`。模型 schema 提供这项指导，保留既有标题和字段长度兼容，不为排版更改历史科研记录。
- 分组题注置于对应组首个可见步骤上方，避免每个节点重复；类型/ID/作业详情归入步骤详情和可访问提示。
- 分支折叠按钮放在卡片内状态行右侧，避开线的进出口。拖拽、缩放、方向切换及布局保存都要保持。方案工具栏移除搜索与独立全屏入口及其快捷键，更多使用竖向省略号；工具栏窄宽度也保持单行。暂停/恢复仅显示图标，保留辅助名称，操作前确认；暂停须说明已提交作业继续运行。
- 布局优化只改变投影，不能删节点、改父依赖、改计划版本或更改计算状态。

### 步骤与结果

结果、异常和运行监控优先；参数和原始输出默认折叠。有内容的步骤说明直接显示在标题下，空说明不占位；步骤 ID 在“技术信息”内。详情分区遵循一级展开条规范，不再用没有区分度的连续横线。

计算只提供“执行记录”一个选择入口：多记录显示选择器，单记录显示静态摘要。失败、重试与采用的记录保留事实，选择同步驱动参数、结果、监控和结构。上游/下游归入默认关闭的“依赖关系”，不可始终平铺。

NEB 核心数值采用一个分栏指标区，数值突出、单位紧邻。标签不能竖排；时间戳使用可读本地时间并保留原始 `datetime`/完整提示。窄面板重新安排图表布局，不能整体缩放成不可读的小字。更新数据或切换图表后保留选择和键盘焦点。

NEB 内只有一个工作区：优化步 → 指标 → 曲线 → 单排路径像 → 内嵌结构。曲线、路径像和查看器帧联动；不同时显示第二个独立结构分区。全屏/返回不得让已加载结构丢失或重置到其他像。

### 结构与轨迹

与 Atom Lens 最新交互方向保持一致：右上“文件、显示、导出、设置”四个图标入口，展开后才显示选项；底部集中播放、视图与结构信息。

结构信息下不平铺常驻解释小字；必要的来源/变换等科学说明放入默认折叠的读取说明，单位仍留在表头。多视图的选中边界与所属视口使用相同外沿圆角，不以直角高亮覆盖圆角容器。

结构文件列表有可折叠标题和数量，最大高度 `min(200px,28dvh)` 并独立滚动；下方3D视口至少320px，文件数量不得挤压视口。列表项长名称省略但提供完整提示。

单帧隐藏轨迹控件。多帧展开态在320px及普通侧栏宽度下仍显示完整可拖动时间轴，窄宽度改为两行而不是隐藏滑块。明确的收起按钮将轨迹栏缩成播放、帧号和展开按钮；收起不暂停、不跳帧。方向、单/双/四视图和鼠标操作使用统一视图入口；粒子、类型、晶胞在结构信息中查看。

正在播放时调整显示、速度、帧率与步长继续播放，原本暂停时也不自动开始。任何移植必须保留 Chem-Agent 的 HTTP 认证、上传、父窗口通信和下载机制；上游 MCP/原生能力不可直接当作本应用已支持的能力。

### 设置与科研记忆

设置导航按“通用 / 智能体与知识 / 计算与运行环境”分组，复用六个入口。服务器与环境只有一份节点列表；同一个节点 ID 内切换 SSH、Runner 或同机连接，停用/移除不可回退启用旧连接。地址、来源和历史检测时间归入连接信息。Agent 每张卡片独立保存，默认选项保存当前卡片后才更新；保留未保存提示，不覆盖其他卡片的草稿。知识页提供默认折叠的 MCP 接入配置，按项目生成 HTTP 地址；stdio 明确标注执行主机。

运行概览显示后端报告的真实宿主名与监控任务状态；不能从 localhost、SSH 隧道或操作系统猜测“常驻在线”。页面明确需要保持平台宿主在线，并将配置启用、程序安装、历史连接检测与实时监控状态分别表述。

记忆检索以“全部记忆 / 按项目 / 按对话”为单一主范围，仅显示有效的下级筛选；隐藏筛选不得参与查询或保存目标。模型设置按独立后端保存边界明确命名，不以一个按钮假装原子保存多个服务。

使用可区分的页面/分节标题字重，不得用全局规则把 `h1/h2/h3/strong` 全部压成 400。导航与列表选中保持中性底色；条目主标题14px以上，元信息13px。设置表单保持固定对齐，科研记忆先展示内容，再提供来源和原始记录。

设置同样采用导航与顶栏一体的外壳，正文为统一圆角内容区。正文标题距内容区顶部24px，窄屏20px，避免紧贴上方分界。

Agent、服务器和配置概览的标题到首张卡片统一24px，服务主行最小高度72px。服务器开关在左，名称与状态在中，检测在右；地址及测试详情归入连接信息。检测结果标为历史检测并可查看时间，关闭设置后可在同标签页短期恢复；配置变化或过期后失效，不能伪装成持续连接。操作提示自动消退，停用服务器不继续挂着旧检测失败状态。

模型菜单顶层固定为 Agent、模型、推理三行，右侧显示当前值；分别展开选择，模型支持搜索，推理强度只使用当前模型真实支持的值。不照搬尚未实现的角色/快速/计划开关。以勾选表达当前选择，仅展开分支使用选中底色。设置卡片展开不改变宽度，滚动条预留稳定空间；英文导航不拆成两行，窄屏改为横向导航。

Agent 和服务器使用12px圆角外框的分组服务卡片，图标 + 名称/摘要 + 状态/操作对齐。计算概览始终保持图标、内容、操作三列。Antigravity 使用官方当前品牌资源，源链接记录在交付说明。

Agent 默认值采用单选语义与明显“默认”标记，保存成功才更新；程序安装、配置和登录验证分别表述。API 没有独立启停字段时，不虚构 Agent 启停开关。SSH 滑轮开关仅表达允许 Agent 使用该主机，连接可用性由显式测试确认；失败要回滚，停用不冒充终止运行中的计算。新增提供本机 SSH 配置选择及手动配置说明，不宣称实现后台不支持的主机创建。

## 5. 响应式、可访问性与交付

### 图标、语言与初始化

- 通用操作图标统一使用 `vendor/lucide/` 固定版本源文件，通过 `ui-icons.svg` 的稳定 ID 引用。24×24 viewBox、2px stroke；通常显示为18px，紧凑位置14–16px。不混用手绘 SVG、文字字形箭头或不同图标库。品牌标志、科学图表、键盘提示和数据关系符号保留自身语义。
- `chemistry.language` 是全局语言偏好的唯一主来源。聊天、设置、科研记忆、已加载的结构查看器和独立标签页必须同步；动态按钮、占位符、辅助名称和菜单也须支持中文 → 英文 → 中文往返。
- 只翻译界面文案。研究标题、用户对话、模型生成的正文、文件名、模型名、账户名及科学参数保留原文，在渲染处标明 `data-no-i18n`。不要在含有界面标签的整个容器上禁用翻译；应把保护范围缩到数据节点。
- 设置页的嵌入/窄屏布局在样式加载前确定。目标分页和语言初始化完成前只显示加载状态，不能先闪现默认分页或旧平台菜单；仅在确认后端支持时展示旧平台入口。初始化失败提供重新加载入口。

1. 至少验证 1440px、768px、390px，以及可调整研究面板的窄宽度。页面不能横向溢出；科学表格可以在自身容器内滚动。
2. 触摸设备主要交互目标至少44px。图标按钮必须有名称；展开/选中状态暴露给辅助技术；遵守 reduced-motion。
3. 新功能先说明主要任务、数据来源、默认与展开内容，再复用现有 token/组件。确有新视觉模式时先更新本规范及公共实现。
4. 运行改动对应的行为测试；菜单、图表、画布和轨迹的交互要在真实浏览器验证。检查空、加载、失败、长标题、明暗主题及窄布局。
5. 视觉检查使用设计 skill 的应用界面规则；记录实际截图和结论，区分工具误报、主观偏好与真实缺陷。不能只靠首页截图宣称所有工作区通过。
6. UI 验证不提交真实计算，也不修改科研记录。展示用夹具必须明确说明；真实数据只能按授权读取。
