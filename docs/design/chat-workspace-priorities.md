# Chem-Agent 对话工作区功能优先级

2026-11-24 · 产品提案。现状基于本仓库 `cfd053d` 的代码与文档。优先级按科研会话中方向错误的代价、操作频率和实现依赖综合判断，未做用户耗时测量。Git 操作不在本次范围内。

## 开发顺序

| 顺序 | 用户任务 | 首版范围 | 验收场景 |
| --- | --- | --- | --- |
| 1 · P0 | 运行中纠正条件 | 有能力的后端默认「引导本轮」，发送菜单提供「下一轮再做」。沿用请求回执，区分等待送达、已送达本轮、已排入下一轮，待送达时可撤回或修改。 | Agent 正在读取轨迹时补充「只分析最后 5 ps」。读取继续，下一次分析决策拿到新条件。刷新后能核对交付位置，相同请求只出现一次。 |
| 2 · P0 | 在对话右侧找到执行现场与成果 | 在现有研究面板顶部提供紧凑的主机与目录入口，展开可复制路径、打开已有目录树。增加「本次对话的成果」，最近一轮在前，可预览、引用、定位来源回复。 | 连续生成两份同名图后，用户可以从对应轮次找到第一张并引用。切到另一会话，主机、目录和文件随会话更新。 |
| 3 · P1 | 在当前目录打开交互终端 | 从同一主机菜单进入终端。首版支持已配置且允许交互登录的 SSH 主机。会话内保留工作目录、环境和前台进程，提供断线状态与重新连接。 | 用测试 SSH 主机从带空格路径进入，验证 `pwd`、连续命令的目录状态、终端缩放及 Ctrl+C。关闭标签、断开连接与取消调度作业各有独立语义。 |
| 4 · P1 | 让 Agent 看见我指出的证据 | 文件预览提供「引用选中行」；输入框 `@` 优先检索本会话成果及当前已浏览目录；终端支持将选中输出附到草稿。 | 用户选取 OUTCAR 的 12 行并发送，模型收到同一段文本及主机、路径、行号。大轨迹引用保留来源和所选帧范围，避免整文件塞入上下文。 |
| 5 · P1 | 回到一个需要我处理的长任务 | 利用已有请求回执、任务通知、审批和作业记录，在会话列表标出「等你回答／需核对／已完成」并跳到对应事件。 | 两个会话同时运行，用户回来能直接进入等待确认的那一项。连接中断后可回看已完成步骤；提交结果未知时先定位原作业再决定是否重试。 |
| 6 · P2 | 找回旧工作，临时问一句 | 先提供按文件名、作业号和对话标题检索并跳回原位置；再考虑借鉴 OpenCode 的旁问，让解释性问题单独作答。 [OpenCode 旁问](https://opencode.ai/docs/cli/tui/#side-questions) | 搜索作业号能打开原会话与相关记录。用户旁问「这个力阈值的单位是什么」后，主任务按原计划推进。 |

## 首版交互与依赖

**运行中输入。** 「只看最后 5 ps」应影响本轮，「做完再导出 CSV」适合排下一轮。内置循环先实现工具批次结束时的交付；Codex、Antigravity 等原生后端分别验证真实协议是否支持活动回合引导，再开放对应选项。一次性回复已结束或回合已切换时，标明未送达，允许改投下一轮。以发往模型的输入或原生后端确认作为送达依据。已经开始执行的命令、已提交的作业保留真实状态；停止 Agent 和取消 Slurm 作业各用自己的操作入口。

**右侧布局。** 收起时只显示类似「cluster-b ▾」的入口，展开显示当前会话工作目录，以及「打开目录」「打开终端」「复制路径」。主机有不同角色时，分别注明 Agent 所在主机和作业所在主机，按用户点选的对象打开终端。保留输入框现有的主机选择，两个入口读取同一会话配置。文件区复用右侧「文件」页签，提供「成果」「目录」两个视图；窄屏沿用现有研究面板抽屉。默认展示最近成果，详细来源按需展开。

**成果来源。** 首版列出已登记成果及可追溯到具体工具或作业的输出。记录能确定的运行、主机、路径和文件版本；区分平台快照与仍会增长的远端日志。同一路径再次输出时，只有存在历史快照才允许选择旧版本。未登记的普通文件可走目录树浏览。避免为发现成果而递归扫描共享盘。 [会话成果存储](../../src/chemistry_agent/workspace_files.py)

**终端生命周期。** 终端属于当前用户和明确选择的主机。连接时显示实际目录；目标目录已移走时提示并允许另选。界面区分正在连接、已连接、已断开，恢复旧进程需要可重连的终端会话支持。新建连接从新的 shell 开始。终端输出默认留在终端，用户选中一段后才能附到对话。Runner 节点的计算可用性与交互登录能力分别判断。

首个可交付版本包含第 1、2 项，可并行开发。第 3 项复用主机与目录入口，第 4 项先接入文件预览，再接入终端选区。验收用模拟工具、测试主机和合成输出，重点观察本轮纠偏是否生效、找回旧成果需要几步、终端是否打开在预期位置。

## 当前分支实现

已接入第 1、2、3、5 项与独立侧边对话。内置 Agent 在模型调用边界读取引导，Codex 使用带目标回合校验的原生引导协议，Antigravity 提供下一轮排队。成果通过右侧独立标签查看，可回到来源回复。主机菜单支持会话工作目录、已登记的作业目录和已启用 SSH 主机的主目录。侧边问答单独保存，使用当前会话绑定的后端与近期对话摘录。
