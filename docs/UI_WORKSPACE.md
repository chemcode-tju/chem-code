## 功能与存储

- 紧凑的聊天/项目导航，项目可创建、重命名、折叠，并收纳多个对话。
- 项目内的「新对话」指定新聊天归属；删除文件夹保留所有对话。后续 UI 调整已移除顶部项目选择框，底层归属接口仍兼容。
- 项目数据使用现有 SQLite 数据库的新增表 `projects` / `project_sessions`，服务启动时自动迁移。查询及写入均检查账户归属，原会话 API 保持兼容。
- 左下角仅保留直接进入设置的按钮。设置采用左侧常规/外观/模型选项卡，一次只显示一个面板，保留原有 ChatGPT 授权、API 地址、密钥、模型与连接测试逻辑。
- 白色/深夜/跟随系统与强调色保存在当前浏览器的 `chemistry.appearance`。不修改账户或模型凭据，不做跨设备同步。底色由模式决定，用户只能自定义强调色，按钮文字按亮度自动选择黑/白。
- 工具表单和工具记录默认折叠；生成结果后展开结果模块。
- 结构查看器的工具栏和设置面板使用统一主题，科学视口与导出图片仍使用查看器自身的背景设置。

## 模块边界

- `projects.py`：独立项目路由、数据表初始化；只在 `api.py` 和 `store.py` 各加入两行接入代码。
- `web/projects.mjs`：项目文件夹、项目对话与管理弹窗。
- `web/theme.js` / `web/theme.css`：共享外观初始化与颜色变量。
- `web/structure/shell-theme.css`：查看器外壳样式，不修改结构解析或三维渲染逻辑。

## 第二轮界面调整

- 侧栏可折叠为单列图标；桌面与窄屏均保留图标栏，折叠偏好保存在当前浏览器。
- 移除文献片段编辑器、Enter 发送提示、顶部项目选择框和输入框底部说明；保留历史参考上下文的只读显示。
- 发送按钮为圆形，模型状态放在其左侧并链接模型设置。侧栏及输入框的加号菜单目前仅提供上传文件。
- 设置页常规提供中文/English 切换，`i18n.mjs` 仅翻译界面，不翻译用户消息、项目名、文件名或模型原文；结构查看器共享语言偏好。
- 外观采用三个带选中边框的模式卡片（系统/白色/深夜），不再显示强调色演示区。字体使用 Apple 系统字体栈和 PingFang SC。
- 文件通过 `attachments.py` 独立路由上传，以 UUID 标识保存在 SQLite BLOB，下载强制为附件。上传、下载与聊天引用按账户隔离，单文件 25 MB，每轮最多 10 个。仅合法 UTF-8 文本提供有界文本片段；其他类型存储但不解析/执行。
- 新增 3 项附件测试覆盖二进制原样下载、文本进入模型上下文、重启持久化、大小/数量限制、跨账户读取/引用和跨站写入拒绝。完整 Python 测试现在为 111 项。
- 浏览器使用模拟模型验证多文件上传、发送与刷新后附件恢复；没有调用真实模型。
