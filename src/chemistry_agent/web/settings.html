计算配置概览

首次使用时，按下列步骤连接集群并建立执行环境。

    在运行 Chemistry Agent 的电脑上创建或启动 AiiDA 服务。

    让 Agent 帮你配置

    告诉 Agent 服务器别名、程序版本和远端路径，它可以帮你登记配置。SSH 密码请在服务器设置里单独填写。

    在对话中配置 →

    服务器连接

    通过 SSH 连接运行计算的服务器。

    添加服务器

    计算软件

    每个版本分别登记，使用服务器上实际可执行文件的绝对路径。

    登记软件版本

    需要加载模块或库时，填写服务器上的环境脚本路径。

    赝势目录

    关联服务器上存放各元素 POTCAR 的根目录，准备计算时按需读取。

    关联远端目录

    调度队列

    从当前服务器查询可用队列，选择后可用于执行环境。

    执行环境

    将软件版本、赝势和队列资源组合成一个环境，供 Agent 准备计算。

    添加执行环境
    账户、GPU 和备用队列

    主队列因提交配额拒绝时，允许尝试这个队列。

    已有兼容配置

    密码保存在运行 Chemistry Agent 的 Mac 钥匙串里。请在这里填写，不要粘贴到对话中。
